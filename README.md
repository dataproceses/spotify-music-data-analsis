# 🎵 Spotify Music & Artist Data Analysis

A data analysis project exploring trends in Spotify music, artist popularity, and audio features. The goal is to uncover insights into genre trends, hit song characteristics, and artist patterns using visualization and exploratory data analysis.

## 📊 Key Features
- Analyze song popularity and artist metrics
- Explore audio features like tempo, danceability, and energy
- Visualize genre trends and release year patterns
- Identify characteristics of top-performing tracks

## 🛠️ Tools Used
- Python, Pandas, NumPy
- Matplotlib & Seaborn for visualization
- Jupyter Notebook
